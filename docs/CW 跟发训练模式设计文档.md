## 1. 架构总览与设计理念

### 1.1 项目定位
跟发训练模式（CW Follow-Transmit & Timing Training）是 **摩语 (MoYu)** 在现有 TXT/EPUB 听抄阅读器（`Reader.jsx`）和摩言密语翻译器（`Translator.jsx`）之上的核心功能扩展。

其核心目标是：**通过采集用户的按键/电键输入时间，与底层 `audioPlayer.js` 生成的标准电码时间轴进行高精度对比，帮助用户训练发报节奏、点划比例与听辨跟发能力。**

## 3. MuseLab CH552G 核心板与 PJ-327D 音频座焊接指南

跟发训练强烈推荐使用 MuseLab CH552G 最小系统板 (USB 接口板) 连接实体电键。针对 3.5mm 音频母座，支持使用市面通用的 PJ-327D 母座。

### 3.1 采购选型说明 (直插式 vs 贴片式 & 编带)

> **核心推荐**：**手工飞线 / 洞洞板焊接强烈推荐选择【直插式 (DIP / 带插针)】！**

1. **直插式 (DIP / 带螺帽插针款 - 推荐 ⭐⭐⭐⭐⭐)**：
   - 针脚较粗长、机械强度高，飞线焊接极其牢固。带螺帽面板款还可以直接固定在外壳面板上，反复拔插电键不会拉扯断线。
2. **贴片式 (SMT / SMD - 不推荐手工飞线)**：
   - 针脚极短平，用于工厂 SMT 贴片。手工飞线焊接时极易因拔插电键的机械应力将焊盘拉脱。
3. **编带 (Tape & Reel)**：
   - 散装/袋装即可，无须买编带。

### 3.3 PJ-327D 3.5mm 音频座引脚定义

PJ-327D 共有 5 个引脚，其底面引脚布局与对应功能如下：

```text
         PJ-327D 3.5mm 音频座俯视/底视图
 ┌───────────────────────────────────────────────┐
 │               [ 3.5mm 插口 ]                  │
 └──────────────────────┬────────────────────────┘
                        │
             (Pin 1)    │    (Pin 2)
              [GND]     │    [Tip/顶端]
                │       │       │
                ▼       │       ▼
               ┌─┐      │      ┌─┐
               │ ├───┐  │  ┌───┤ │
               └─┘   │  │  │   └─┘
                     │  │  │
                    ┌┴──┴──┴┐
                    │Pin 3  │ (Ring/环端)
                    │[Ring] │
                    └───────┘
```

* **Pin 1 (GND / Sleeve 套管)**：地线公共端（连接电键的金属外壳/公共端）。
* **Pin 2 (Tip / 顶端)**：对应 3.5mm 电键插头顶端，用于**手键 (Straight Key) 信号** / **自动键的划 (Dah)** 信号。
* **Pin 3 (Ring / 环端)**：对应 3.5mm 电键插头环端，用于**自动键的点 (Dit)** 信号。
* **Pin 4 / Pin 5**：内部常闭插拔检测脚，焊接时**直接悬空不接**。

---

### 3.4 详细焊接与接线映射表 (Wiring Guide)

将 MuseLab CH552G 开发板与 PJ-327D 母座按如下对应关系用飞线焊接：

```text
┌───────────────────────┐                    ┌─────────────────────────┐
│ MuseLab CH552G 开发板 │                    │ PJ-327D 3.5mm 音频母座  │
├───────────────────────┤                    ├─────────────────────────┤
│ GND 焊盘 (上排或下排)  │ <────────────────> │ Pin 1 (GND / Sleeve套管)│
│ P14 焊盘 (上排第6脚)  │ <────────────────> │ Pin 2 (Tip 顶端 / 手键) │
│ P15 焊盘 (上排第5脚)  │ <────────────────> │ Pin 3 (Ring 环端 / 点Dit)│
└───────────────────────┘                    └─────────────────────────┘
                                                Pin 4 (悬空未接)
                                                Pin 5 (悬空未接)
```

#### 手键 (Straight Key) 与自动键 (Paddle) 适配说明：
1. **普通手键 (单音/两芯大体插头 3.5mm TS)**：
   - 插入插座后，插头 Tip 接触 Pin 2 (P14)，Sleeve 接触 Pin 1 (GND)。按下手键即可直接触发 `P14` 导通接地，完美工作。
2. **双音自动键 (双桨/三芯插头 3.5mm TRS)**：
   - 划 (Dah) 触发 `P14` (Pin 2)，点 (Dit) 触发 `P15` (Pin 3)。单片机固件自动识别点划按键。

## 4. 软件核心模块设计

### 4.1 多源按键采集 Hook (`useKeyInput.js`)

支持 CH552G 硬件电键 (高精度 Serial/HID) 与键盘 Space 键 (临时测试)。

### 4.2 目标时间轴与标准单元 (`morseCode.js` & `audioPlayer.js`)

复用 MoYu 现有的 `textToMorseTokens` 与 `playbackConfig`（包含 `wpm`）：
- $\text{unitDurationMs} = \frac{1200}{\text{WPM}}$

### 4.3 双主题极简 Canvas 示波器组件 (`MorseTimelineCanvas.jsx`)

内嵌于 `Reader.jsx` 正文底部：
- 60FPS 原生 Canvas 渲染，高度 120px。
- 根据 `.dark` 自动无缝切换 Canvas 色板，取消文字前缀。

### 4.4 评分与分析引擎 (`morseTimingAnalyzer.js`)

在跟发结束时生成报告：
- 点划比例 (DOT/DASH ratio 1:3 校验)。
- 字符间隔与单词间隔偏差。
- 节奏稳定性标准差 (Standard Deviation)。
