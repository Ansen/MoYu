## 2. 游戏核心玩法设计：《电码先锋：信号风暴》

### 2.1 游戏世界观与角色设定
- **玩家身份**：深海“鹦鹉螺号”潜艇无线电通信特工。
- **敌方对手**：潜伏在深海的“电磁巨兽 / 噪音母体 Boss”与敌方驱逐舰。
- **核心任务**：Boss 正在释放强大的电磁干扰光束阻止潜艇上浮。玩家必须凭借电键，精准招架对冲敌方干扰波，蓄力反击摧毁 Boss 的天线与核心！

### 2.2 核心对决机制：“激光对冲（Beam Clash）”

```
[玩家潜艇 / 防卫防线]                                       [BOSS: 电磁干扰巨兽]
  HP: ████████░░ (80%)                                      HP: ████████████░░ (60%)
  COMBO: 24   FEVER: [██████████] READY!                    PHASE: 2/3 (狂暴状态)
─────────────────────────────────────────────────────────────────────────────
                     【中央对冲对决轨道 (Radar Scope)】
[判定框/防线] <==== 蓝光反弹对冲 === [碰撞点] === 红光电码波 <==== [BOSS 发射源]
(用户拍发)                             💥 (对撞点)        (· 点 / —— 划)
```

1. **敌方发射（电脑示范音轨）**：
   - Boss 从右侧射出电码脉冲波：
     - **短光球（· 点）**：长度为 1T 的金色能量球。
     - **长光束（— 划）**：长度为 3T 的长条激光柱。
     - **空隙（Space）**：点划内 1T 间隔、字符间 3T 间隔。
   - 伴随电脑标准的 **380Hz 沉稳基准音**。
2. **玩家对冲抵消（招架动作）**：
   - **点（Dit）**：当短光球进入左侧判定区时，**短按电键** $\to$ 防线射出一发蓝色光子弹，在判定线上与敌方光球**“轰”一声对撞中和碎裂**！
   - **划（Dah）**：当长光束头部进入判定区时，**按下并按住电键** $\to$ 防线展开蓝色激光护盾，持续吸收红光束；在尾部恰好松开，长光束完全蒸发瓦解！
   - 伴随玩家拍发的 **475Hz 大三度和声音效**。
3. **同进同出（Perfect 判定与防守反击）**：
   - **PERFECT（时序误差 $\le 15\text{ms}$）**：
     - 双波不仅在碰撞点完美抵消，还会触发**“防守反弹（Parry Reflect）”**：蓝光化作一道追踪鱼雷反抽 Boss，Boss 掉血！
     - 触发 **380Hz + 475Hz 和声共振与金色泛音**，Combo +1，Fever 能量槽累加。
   - **GREAT（时序误差 $16\text{ms} \sim 35\text{ms}$）**：
     - 普通抵消，无反击伤害，Combo 保持。
   - **MISS / INCOMPLETE（长划按短了、按晚了或漏按）**：
     - 抵消失败！敌方残余光束直接轰击潜艇外壳，玩家扣血（HP -10%）；
     - 屏幕发生剧烈的电磁抖动（Glitch 杂音与雪花特效），Combo 清零。

### 2.3 进阶战斗系统：部位破坏与 FEVER 终结技
1. **Boss 部位破坏机制（Targeting Subsystems）**：
   - Boss 拥有不同弱点部件：
     - **雷达发射天线（弱点：单点类字符 E, I, S, H）**：破坏后，Boss 弹幕速度降低 20%。
     - **高压干扰电容（弱点：长划类字符 T, M, O）**：破坏后，消除全屏杂波干扰。
     - **中央能量核心（弱点：常用 Q 简语，如 `SOS`, `73`, `UR 599`）**：击破直接斩杀！
2. **FEVER 暴气超频模式**：
   - 连续达成 10 次 Perfect，FEVER 蓄力槽满。
   - 触发时屏幕变暗，雷达轨道泛起霓虹蓝光，进入超频模式：**反击伤害提升 200%，玩家每次 Perfect 消除都附带全屏微弹幕清屏！**
3. **QSO 决胜对波（Final Clash）**：
   - Boss 濒死狂暴时，蓄力 3 秒释放终极全屏电码连波（如 `SOS SOS SOS`）。
   - 玩家必须全神贯注完成一整串连发抵消，成功则潜艇主炮齐射，彻底击沉 Boss！

## 4. 统一硬件与全生态输入抽象层

为了让游戏在不同设备上无缝运行，系统设计了**统一输入抽象层（Input Abstraction Layer）**。底层支持三种输入形态，上层引擎完全透明：

```
  [物理输入源 1: 键盘]      [物理输入源 2: 鼠标]      [物理输入源 3: 专业电键]
    - Space (手键)           - 鼠标左键 (手键/点)       - 3.5mm 手键 / 自动键
    - J 键 (点)              - 鼠标右键 (划)                 │
    - K 键 (划)                                              ▼
         │                        │                 [CH552G 免驱 USB 适配器]
         └────────────────────────┼──────────────────────────┘
                                  ▼
                    【统一输入事件引擎 (Input Engine)】
              - keyState: { dit: boolean, dah: boolean }
              - timestamp: performance.now() (微秒级时钟)
              - event: 'KEY_DOWN' | 'KEY_UP'
                                  │
                                  ▼
                   【游戏消除判定与声学和声引擎】
```

### 4.1 硬件方案落地：CH552G 免驱 USB-HID 适配器
针对已选定的 **CH552G 开发板**（成本仅 6.8 元）：
- **全免驱设计**：枚举为标准 USB 键盘/游戏手柄，Windows / macOS / Linux 全平台免驱。
- **3.5mm TRS 引脚映射**：
  - `Sleeve (地线)` $\to$ `GND`
  - `Tip (点/手键)` $\to$ `P1.4`
  - `Ring (划)` $\to$ `P1.5`
- **详细制作与 Arduino 烧录指南**：已归档至 [docs/hardware_ch552g_firmware_guide.md](file:///f:/Code/github/MoYu/docs/hardware_ch552g_firmware_guide.md)。
