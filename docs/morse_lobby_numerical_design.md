## 1. 底层电码时钟与物理时序常数 (Core Morse Clock)

本系统的所有游戏模式均严格建立在国际业余无线电联盟（IARU）与国际电信联盟（ITU）的 **PARIS 标准**时序体系之上，确保游戏娱乐的同时具有绝对严谨的专业教学价值。

### 1.1 基元时钟常数公式
标准单词 `"PARIS "` 规定为 50 个基元时间单位（Unit Element，记为 $T$）：

$$T = \frac{1200}{\text{WPM}} \quad (\text{单位: 毫秒 ms})$$

各速率下的基准时间分配表：

| 字速 (WPM) | 1个点 (1T) | 1个划 (3T) | 点划间隔 (1T) | 字符间隔 (3T) | 单词间隔 (7T) | 适用场景 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **8 WPM** | 150 ms | 450 ms | 150 ms | 450 ms | 1050 ms | 新手入门 / 慢速破译 |
| **12 WPM** | 100 ms | 300 ms | 100 ms | 300 ms | 700 ms | 基础通关 / 避障飞行 |
| **15 WPM** | 80 ms | 240 ms | 80 ms | 240 ms | 560 ms | 进阶对战 / 标准考核 |
| **20 WPM** | 60 ms | 180 ms | 60 ms | 180 ms | 420 ms | 高手狂暴 / 极限挑战 |
| **25 WPM** | 48 ms | 144 ms | 48 ms | 144 ms | 336 ms | 大神级电码风暴 |

## 2. 动态判定窗口与容差模型 (Tolerance & Grading Formula)

在不同 WPM 下，人类生理反应时间与时基误差占比不同。若采用固定毫秒判定会导致高速时极难、低速时无挑战。
因此判定窗口采用 **“基元比例动态缩放 + 物理生理保底值”** 的双重约束：

### 2.1 起振/落振边沿时差 ($\Delta t_{\text{edge}}$)
设电脑标准信号开始时刻为 $t_0$，用户按下时刻为 $t_u$，边沿误差定义为：
$$\Delta t_{\text{edge}} = t_u - t_0 \quad (\text{负值代表抢拍，正值代表慢拍})$$

### 2.2 点划持续时长偏差 ($\Delta D$)
设标准持续时长为 $D_0$（点为 $1T$，划为 $3T$），用户按键持续时长为 $D_u$，持续偏差比为：
$$\text{RatioError} = \frac{|D_u - D_0|}{D_0}$$

### 2.3 判定等级数学模型

| 等级 (Grade) | 起键边沿容差 ($\Delta t_{\text{edge}}$) | 持续时长误差 ($\text{RatioError}$) | 得分倍率 | 听觉反馈 | 视觉反馈 |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **PERFECT** | $|\Delta t| \le \min(0.25T, 25\text{ms})$ | $\le 20\%$ | $100\%$ | 380Hz+475Hz 纯正和声 + 泛音 | 绚丽金色粒子暴击，反弹反击飞弹 |
| **GREAT** | $|\Delta t| \le \min(0.50T, 50\text{ms})$ | $\le 40\%$ | $70\%$ | 基础双音重叠 | 银白微粒子中和，抵消无反击 |
| **GOOD** | $|\Delta t| \le \min(0.75T, 75\text{ms})$ | $\le 60\%$ | $40\%$ | 声音错位交叠 | 弱黄色光晕擦碰，减免部分伤害 |
| **MISS** | 超出 GOOD 范围或漏发/按错 | $> 60\%$ | $0\%$ | 只有电脑孤立单音或哑音 | 红色破碎，玩家受损，屏幕电磁扰动 |

### 3.1 模式一：【电码战役 · 招架与超导充能 (Combat Mode)】

结合用户设想的**“对撞招架（Parry）”**与**“充能大招（Railgun Discharge）”**双机制。

#### 核心数值表：
- **玩家生命值 (Player HP)**：`100 点`
- **Boss 生命值 (Boss HP)**：
  - 第 1 关（侦察浮标）：`200 点`
  - 第 2 关（干扰雷达站）：`500 点`
  - 第 3 关（深海巨舰 Boss）：`1200 点`
- **招架反弹伤害 (Parry Damage)**：
  - 每次 PERFECT 抵消：造成 $D = 8 \times (1 + \text{Combo} \times 0.05)$ 点反击伤害。
- **电容蓄力槽 (Capacitor Gauge, 0 ~ 100%)**：
  - 命中一个点（·）：充能 `+4%`
  - 命中一个划（—）：充能 `+12%`
  - 连续整词全 PERFECT：额外奖励 `+15%`
  - 产生 MISS：电容短路漏电，损失 `-20%`
- **超导磁轨炮必杀 (Railgun Discharge)**：
  - 充能达到 100% 时自动激活，蓄力松手释放：
  - 贯通光束对 Boss 造成 $D_{\text{railgun}} = 150 \times (1 + \frac{\text{WPM}}{15})$ 巨额暴击伤害，并强制清空场上所有敌方弹幕！
- **受击伤害 (Damage to Player)**：
  - 漏掉点光球：受到 `8 点` 伤害。
  - 漏掉长划光束：受到 `18 点` 伤害。

---

### 3.2 模式二：【深海盲航 · 声纳重力避障 (Sonar Flight)】

将点划长短直接映射为**深海潜艇的垂直动力学**，打造比 Flappy Bird 更具节奏韵律的跑酷模式。

#### 物理与动力学数值模型：
- **横向推进速度 (Scroll Speed)**：
  - 画面按真实电码速率匀速右移：$V_x = 100\text{ px/s} \times (\frac{\text{WPM}}{10})$。
- **重力与下沉加速度 (Gravity)**：
  - 默认自然下沉加速度：$g = 650\text{ px/s}^2$。
  - 终端下沉最大速度：$V_{y,\max} = 320\text{ px/s}$。
- **推进升力加速度 (Lift Acceleration)**：
  - 按下电键时，垂直引擎喷射升力：$a_{\text{lift}} = 1100\text{ px/s}^2$（克服重力产生净向上加速度 $450\text{ px/s}^2$）。
- **短按瞬时冲量 (Dit Impulse)**：
  - 短按（点 ·）触发瞬态向上冲量脉冲：$V_y \leftarrow -160\text{ px/s}$（轻盈跃升一步）。
- **长按持续巡航 (Dah Cruise)**：
  - 长按（划 —）持续提供升力，爬升一道角度约 35° 的平滑斜坡。
- **地形隧道生成算法 (Cave Generation)**：
  - 上下暗礁通道的空隙严格根据电脑播放的电码波形生成：
  - 通道垂直安全宽度：$H_{\text{safe}} = 150\text{ px}$。
  - **只要玩家的点划节奏与电脑 100% 同步，潜艇重心将完美悬浮在通道正中心**，呈现出极度丝滑优美的航迹！

### 3.3 模式三：【密电破译 · 锁芯共振开锁 (Cipher Safe Cracker)】

针对想要**专项攻坚特定易混字母**（如 `S/H/5`、`K/C/Y`、`B/D/6`）的刻意练习模式。

#### 共振数值算法：
- **密码锁芯级数**：每扇防爆门由 3 ~ 6 组密电锁芯构成。
- **谐波共振指数 (Resonance Index, $R$)**：
  $$R = 100\% - (\text{RatioError} \times 40\% + \text{EdgeErrorRatio} \times 40\% + \text{SpaceError} \times 20\%)$$
- **解锁阈值**：
  - 当整段字符拍发结束，若 $R \ge 85\%$，锁芯弹子发出清脆机械咬合声，亮起绿灯；
  - 若 $R < 85\%$，锁芯轻微回弹抖动，提示具体偏差（如“划偏短 12%”），允许立刻再次尝试；
  - 连续解锁全部锁芯，防爆门机械开箱，爆出通联情报与勋章。

### 3.4 模式四：【深空寻踪 · 无线电钓鱼与历史密电图鉴 (Cosmic Signal Fishing)】

面向无线电情怀玩家的沉浸式收集模式，在真实电离层杂音（QRN/QSB）中寻踪破译。

#### 信号与破译数值体系：
- **信噪比环境 (Signal-to-Noise Ratio, SNR)**：
  - 真实模拟无线电白噪声与衰落（-3dB ~ +15dB），辅以 380Hz 纯正侧音。
- **信号咬钩与锁定槽 (Lock-on Meter, 0% ~ 100%)**：
  - 调谐旋钮捕捉到微弱信号时进入“咬钩跟发”；
  - 玩家跟发对齐率维持在 90% 以上时，锁定槽以每秒 `+12%` 的速度充能；
  - 达到 100% 时“起钩”成功，信号瞬间清晰，完全解析出一段真实历史通联档案。
- **图鉴藏品库（示例）**：
  - 📻 《泰坦尼克号 MGY 最后的 CQD/SOS 求救电文 (1912)》
  - 🚀 《阿波罗 11 号登月舱地面确认信号》
  - 🚢 《诺曼底登陆“霸王行动”气象通报密电》
  - 🛸 《深空旅行者 1 号脉冲标旗代码》

## 4. 统一按键状态机与底层驱动模型

无论用户使用哪种输入设备，统一在前端抽象为毫秒级状态事件：

```javascript
// 统一按键事件模型
class MorseInputEngine {
  constructor() {
    this.keyState = {
      isDown: false,
      downTimestamp: 0,
      upTimestamp: 0,
      currentDuration: 0,
      type: 'STRAIGHT' // 'STRAIGHT' | 'DIT' | 'DAH'
    };
  }
}
```

### 输入源统一映射表：
1. **键盘 Space 键**：手键模式（按下即通，松开即断）。
2. **键盘 J 键 / 鼠标左键**：自动键“点（Dit）”。
3. **键盘 K 键 / 鼠标右键**：自动键“划（Dah）”。
4. **CH552G 硬件适配器**：固件原生发送 `J`（点）和 `K`（划），与键盘事件 100% 复用，代码零改动！

```typescript
interface DiagnosticReport {

  ditDahRatio: number;       // 实测点划比 (标准 1:3.0)
  ratioDeviationPercent: number; // 比例偏离百分比
  averagePhaseShiftMs: number;  // 平均起键相位偏移 (负数抢拍, 正数慢拍)
  intraSpaceAccuracy: number;   // 字符内点划间距准确率 (0~100%)
  interSpaceAccuracy: number;   // 字符间大间隔准确率 (0~100%)
  prescription: string[];    // 算法生成的手癖纠错处方建议
}
```
