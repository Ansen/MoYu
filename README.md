# 📡 摩语 (MoYu) - 摩尔斯密码与中文互译工具

> “在无声的电波中，传递我们的专属密语。”

**摩语 (MoYu)** 是一款轻量、极简且有趣的摩尔斯密码与中文互转工具。不论你是想在摸鱼时发送防偷窥的加密信息、在社交平台发布专属暗号，还是硬核查阅电码标准，摩语都能为你提供丝滑的编解码体验。

## ✨ 核心特性 (Features)

*   **🇨🇳 中文完美支持**：打破传统摩斯码只支持英文的限制，实现中文汉字与摩斯电码的精准互转。
*   **⚡️ 毫秒级极速转换**：边输入边转换，所见即所得。
*   **📋 一键复制与分享**：转换结果一键复制，方便快速粘贴到微信、QQ 等社交软件。
*   **🎨 极简UI设计**：专注于输入与输出本身，无广告，无冗余功能。
*   **📱 响应式布局**：完美适配 PC 端与移动端（未来将推出原生 App 版本）。
